# RE:WAVE — Audio Remix Studio

Браузерный аудиоредактор в стиле Slowed + Reverb / Nightcore. Работает как статический сайт: Node.js, сервер, база данных и сборка не нужны.

## Возможности

- Загрузка нескольких аудиофайлов: MP3, WAV, OGG, M4A, FLAC и другие форматы, которые умеет декодировать браузер.
- Очередь треков: выбор, удаление, переключение и очистка.
- Воспроизведение, пауза, перемотка по waveform, предыдущий / следующий трек, повтор.
- Пресеты **Slowed + Reverb** и **Nightcore**.
- Отдельные настройки Speed, Pitch, Reverb, Bass boost и Volume.
- Экспорт результата в WAV.
- Аудиофайлы декодируются и обрабатываются локально в браузере — сайт не отправляет их на сервер.
- Адаптивная вёрстка для мобильных экранов.

## Быстрый запуск

1. Распакуй архив.
2. Открой `index.html` в браузере. Для полного режима обработки рекомендуется запуск через локальный статический сервер или GitHub Pages (AudioWorklet работает в secure context; `localhost` тоже подходит).
3. Нажми **Добавить треки**, выбери аудио и используй пресеты или настрой эффекты вручную.

Для локального запуска можно воспользоваться расширением **Live Server** в VS Code либо командой `python -m http.server 8000` из папки проекта, затем открыть `http://localhost:8000`.

## Публикация на GitHub Pages

### Вариант A — сайт на адресе `username.github.io`

1. Создай на GitHub публичный репозиторий с точным именем `username.github.io` (вместо `username` — твой GitHub username).
2. Загрузи **содержимое** этой папки в корень репозитория: `index.html`, `styles.css`, `app.js` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Через некоторое время сайт появится по адресу `https://username.github.io`.

### Вариант B — сайт проекта

1. Создай обычный репозиторий, например `rewave-studio`.
2. Загрузи файлы проекта в корень репозитория.
3. В **Settings → Pages** выбери **Deploy from a branch → main → /(root) → Save**.
4. Адрес будет вида `https://username.github.io/rewave-studio/`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Важно про DSP-модуль

Для независимой регулировки темпа и высоты тона используется библиотека **SoundTouchJS** (`@soundtouchjs/audio-worklet`, версия 2.1.1), подключаемая с jsDelivr CDN. Её процессор работает через Web Audio API AudioWorklet. При недоступности CDN сайт переключается на запасной режим: аудио продолжает воспроизводиться, но скорость и высота тона становятся связанными.

Библиотека SoundTouchJS распространяется по лицензии MPL-2.0. Исходный код и лицензия: https://github.com/cutterbl/SoundTouchJS

## Ограничения

- Поддерживаемые форматы импорта зависят от декодеров конкретного браузера. WAV и MP3 обычно поддерживаются лучше всего.
- Экспорт в этой версии — WAV (PCM 16-bit). Это несжатый формат, поэтому файл может быть больше исходного MP3.
- Очень длинные треки требуют свободной оперативной памяти, так как обработка выполняется на устройстве пользователя.
- Если CDN недоступен, независимое изменение pitch и speed и DSP-экспорт через SoundTouchJS будут недоступны; сайт сообщит об этом и включит запасной вариант.
